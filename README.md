# Painel de Equalização dos Oficiais de Justiça da Capital – TRT da 1ª Região

Painel interativo do **Índice de Carga Equalizada (ICE)**: https://evt81.github.io/equalizacao-ojs-capital/

> **Documento técnico preliminar**, para deliberação da Administração. Não é ato oficial do Tribunal. Os números são indicativos e serão recalculados depois da validação dos dados.
>
> Elaboração: Secretaria de Apoio Judiciário (SAJ).

Este repositório contém apenas o painel publicado (`index.html`, arquivo único, sem dependências externas). Os dados exibidos são agregados por área; os mandados por Oficial de Justiça aparecem sem identificação.

O código, a base de dados e a proposta completa são mantidos em repositório privado. O painel é atualizado a partir dele.
